Give Your AI Agent Shopping Capability

One URL turns any MCP client into a shopping agent: product search, price comparison, flights, attributed buy links and order tracking — free, hosted, 5-minute setup.

The one-line integration

{
  "mcpServers": {
    "baydeep": { "url": "https://mcp.baydeep.com/mcp" }
  }
}

That's the whole setup. Your agent gets 11 tools — four work immediately without any key:

  • catalog_overview — what the catalog contains and how to use each product type
  • shelf_search — search 7,000+ stocked products and fares
  • flight_search — flight fares by city and date, pre-attributed booking links
  • shelf_item — full detail for any item

The remaining tools (live AliExpress search, hot products, detail lookups, convert_link, affiliate_orders) unlock with a free API key — mint one in the console, no signup.

REST if you prefer

The same catalog is available as plain HTTP at api.baydeep.com/v1 — /shelf?q=, /search, /item/:id, /convert, /orders, /trial. Works from any language with an HTTP client.

What your agent can do with it

  • Recommend real products with price, sales count and rating — from a live, daily-refreshed catalog
  • Compare flight fares across 18+ cities with dates
  • Close the loop: give users attributed buy links, and track every driven purchase in affiliate_orders
  • Earn: you earn a commission share on commission-eligible purchases your agent drives

Why a gateway instead of a direct AliExpress integration

Direct merchant integrations mean app reviews, API contracts, quota management, currency handling and affiliate-network onboarding — weeks of work before your agent's first search. A gateway packages all of it as normalized tools with a keyless trial tier. BayDeep's catalog is AliExpress affiliate inventory plus travel (Aviasales, Trip.com) — one integration, multiple merchants, commission on all of it.
