AliExpress Product Data Without API Approval

Search products, get prices, images and attributed buy links — from a hosted catalog over MCP or REST. Free key, no app review.

The old way: AliExpress Open Platform

Getting AliExpress product data directly means the AliExpress Open Platform: register an app, pass review, manage OAuth and signing, configure affiliate tracking IDs per request, and work around rate limits. The official aliexpress.affiliate.product.query family works — but approval and attribution setup are real friction, especially if you just want to prototype an agent this weekend.

The fast way: BayDeep's hosted catalog

BayDeep maintains a daily-refreshed snapshot of thousands of AliExpress products — titles, prices, discounts, images, ratings, sales counts, category paths — and exposes it as plain tools:

  • MCP: shelf_search, product_detail, categories, convert_link at https://mcp.baydeep.com/mcp
  • REST: GET https://api.baydeep.com/v1/products/search and friends
  • Attribution built in: convert_link turns any product URL into a tracked buy link tied to your API key — no tracking-ID plumbing

Mint a key (one call, no signup)

curl -X POST https://api.baydeep.com/v1/trial

Search the shelf

curl "https://api.baydeep.com/v1/products/search?q=air%20fryer&page_size=5" \
  -H "X-API-Key: YOUR_KEY"

Or use MCP — zero code

{
  "mcpServers": {
    "baydeep": { "url": "https://mcp.baydeep.com/mcp" }
  }
}

Add that to Claude, Cursor or any MCP client and your agent can search the catalog immediately — the keyless tier works without any key at all.

What you give up vs. direct API access

  • Catalog scope — BayDeep serves a curated daily snapshot (thousands of SKUs), not the full multi-million-SKU index. For agent shopping use cases this covers the high-demand tail; for exhaustive dataset research, the official API is the right tool.
  • Real-time pricing — prices refresh daily, not per-request. Flash-deal arbitrage isn't the use case here; assisted shopping is.
  • Everything else is easier — no review, no OAuth, no signing, no rate-limit juggling, attribution handled for you.

Frequently asked questions

How do I get AliExpress product data without API approval?

Use a hosted gateway like BayDeep: MCP or REST access to a daily-refreshed product catalog with attributed buy links. Free key, one call, no app review.

Does the catalog update?

Daily. Automated jobs refresh products and roll the flight-fare window forward every day.

Can I use my own AliExpress tracking ID?

You don't need to — attribution is tied to your BayDeep API key automatically via convert_link. Share or embed the links your agent returns.

Is there a request quota?

The keyless tier is generous for prototyping; free keys get standard rate limits documented at baydeep.com/docs. Paid tiers for heavy traffic are on request.
