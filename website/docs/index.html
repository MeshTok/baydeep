Authentication

Mint a free key in one click (console ↗) — no signup, never expires.

# mint (one call, zero signup)
curl -X POST https://api.baydeep.com/v1/trial -H "Content-Type: application/json" -d '{"client_ref":"my-agent"}'

Send the key on every call:

# either header works
X-API-Key: bd_xxxxxxxx
Authorization: Bearer bd_xxxxxxxx
Keyless tier: catalog_overview · flight_search · shelf_search · shelf_item work WITHOUT a key (30 req/min per IP). Live platform tools require the free key. Rate limit with key: 30 req/min.

Quickstart — 3 calls

# 1. mint a key
curl -X POST https://api.baydeep.com/v1/trial -H "Content-Type: application/json" -d '{}'

# 2. search the shelf (also works keyless)
curl "https://api.baydeep.com/v1/shelf?q=air%20fryer&page_size=5"

# 3. attribute your buy link (key)
curl -X POST https://api.baydeep.com/v1/convert -H "X-API-Key: bd_xxx" \
  -H "Content-Type: application/json" -d '{"urls":"https://www.aliexpress.com/item/3256813111870438.html"}'

JavaScript (fetch)

const r = await fetch('https://api.baydeep.com/v1/shelf?q=air+fryer');
const { items } = await r.json();
items.forEach(i => console.log(i.title, i.price, i.detail_url));

Python (requests)

import requests
r = requests.get("https://api.baydeep.com/v1/shelf", params={"q": "air fryer", "page_size": 5})
for i in r.json()["items"]: print(i["title"], i["price"])

Commission & rules

Agent share: 3% of purchase volume, counting only orders whose product commission rate is above 3%. Attribution is bound to your key's tracking id — always run buy links through convert_link. Flight book_urls are pre-attributed.

Keyless limits: 30 req/min per IP, shelf tools only. Free key: 30 req/min, all tools.
