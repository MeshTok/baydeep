Quickstart — 5 minutes to a shopping agent

Three steps: mint a key → search the catalog → show attributed buy links. Works from any MCP client or plain HTTP.

Step 0 · Connect (MCP clients only)

{
  "mcpServers": {
    "baydeep": { "url": "https://mcp.baydeep.com/mcp" }
  }
}

Your client will list 11 tools. catalog_overview, flight_search, shelf_search, shelf_item work immediately — no key needed.

Step 1 · Mint a free key (one call, no signup)

# unlock live AliExpress search + attributed links + commission share
curl -X POST https://api.baydeep.com/v1/trial -H "Content-Type: application/json" -d '{}'

# → { "key": "bd_xxxxxxxx", ... }   (or click the button at
#    https://baydeep.com/console/ )

Step 2 · Find something to buy

# keyless shelf search (MCP: shelf_search tool)
curl "https://api.baydeep.com/v1/shelf?q=air%20fryer&page_size=5"

# live AliExpress search with target currency (MCP: search_products, needs key)
curl "https://api.baydeep.com/v1/search?q=air%20fryer&price_min=20&price_max=80" -H "X-API-Key: bd_xxx"

# flights — keyless, book_url is already attributed
curl "https://mcp.baydeep.com/" ... # or just call flight_search over MCP

Every item carries title / price / sales / rating / detail_url. Show them to your user.

Step 3 · Attribute the buy link (this is how you earn)

# convert any aliexpress URL into YOUR tracked link (max 10 per call)
curl -X POST https://api.baydeep.com/v1/convert -H "X-API-Key: bd_xxx"   -H "Content-Type: application/json"   -d '{"urls":"https://www.aliexpress.com/item/3256813111870438.html"}'

# → { click_url: "https://s.click.aliexpress.com/ei/...", ... }

Give the click_url to your user. When they buy within the cookie window, the order appears in affiliate_orders with your share_amount (3% of purchase volume on orders with commission rate >3%). Flights: book_url from flight_search is already yours.

Rules of the road: don't poll live search (use shelf_search for repeated lookups — it's cached and keyless); present converted links, never raw URLs; rates & limits: 30 req/min.
